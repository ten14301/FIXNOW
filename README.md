# FixNow

**FixNow** คือแอปพลิเคชันสำหรับการจัดการการแจ้งซ่อมและการบริหารจัดการห้องภายในอาคารสถานที่ โดยมีฟีเจอร์ต่างๆ เพื่อช่วยให้การทำงานสะดวกและมีประสิทธิภาพยิ่งขึ้น

## ผู้พัฒนา
- **ชื่อผู้พัฒนา**: นายนิติธร กองแดง

## ฟีเจอร์หลัก
1. **รายงาน**: ให้ผู้ใช้งานสามารถดูรายงานการแจ้งซ่อมต่างๆ ได้อย่างง่ายดาย
2. **การแจ้งเตือน**: ระบบจะแจ้งเตือนผู้ใช้งานและผู้ดูแลระบบในกรณีที่มีการแจ้งซ่อมหรือเหตุการณ์สำคัญเกิดขึ้น
3. **การแจ้งซ่อม**: ผู้ใช้งานสามารถแจ้งปัญหาหรือซ่อมแซมสิ่งต่างๆ ภายในอาคาร พร้อมระบุรายละเอียดและแนบไฟล์ภาพหรือวิดีโอ
4. **การจัดการห้อง**: ระบบสามารถจัดการห้องได้อย่างมีประสิทธิภาพ เช่น การเพิ่มหรือแก้ไขข้อมูลห้อง
5. **การจัดการผู้ใช้งาน**: ผู้ดูแลระบบสามารถจัดการข้อมูลผู้ใช้งาน เช่น เพิ่ม ลบ หรือแก้ไข
6. **การเพิ่มห้อง**: ผู้ใช้งานสามารถเพิ่มห้องใหม่เพื่อใช้ในการแจ้งซ่อม
7. **แชท**: ระบบรองรับการแชทภายในแอปพลิเคชัน เพื่อให้ผู้ใช้งานและผู้ดูแลระบบสามารถสื่อสารกันได้ง่าย
8. **การจัดการสถานะ**: ผู้ดูแลระบบสามารถจัดการสถานะของการแจ้งซ่อม และสามารถตรวจสอบสถานะต่างๆ ได้
9. **การเข้าสู่ระบบด้วย QR Code**: ผู้ใช้งานสามารถเข้าสู่ระบบได้ง่ายๆ ด้วยการสแกน QR Code

## การติดตั้ง
โปรเจกต์นี้ใช้ **Flutter** และ **Node.js** เป็นเทคโนโลยีหลักในการพัฒนา คุณสามารถติดตั้งและเริ่มใช้งานได้ตามขั้นตอนดังนี้:

1. **ติดตั้ง Dependencies**:
    - สำหรับ Flutter:
    ```bash
    flutter pub get
    ```

2. **การตั้งค่าและรันโปรเจกต์**:
    - รันแอป Flutter:
    ```bash
    flutter run
    ```
